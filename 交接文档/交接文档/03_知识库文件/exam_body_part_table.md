# 检查-部位知识表

当前 MVP 先处理用户粘贴的报告文字。图片 OCR、报告截图识别和自动提取图片文字放到后置增强阶段。

## 彩超 / B 超

| 检查部位 | 常见报告关键词 | 可能需要补充的资料 |
| --- | --- | --- |
| 甲状腺 | 结节、囊实性、钙化、血流信号、TI-RADS | 甲状腺功能、既往超声、家族史、是否做过穿刺 |
| 乳腺 | 结节、囊肿、导管扩张、BI-RADS、腋窝淋巴结 | 乳腺钼靶、既往超声、月经/哺乳情况、家族史 |
| 肝胆胰脾 | 肝囊肿、脂肪肝、胆囊息肉、胆结石、脾大 | 肝功能、乙肝/丙肝史、腹痛发热、既往影像 |
| 泌尿系 | 肾结石、积水、囊肿、输尿管扩张、前列腺增生 | 尿常规、肾功能、疼痛/血尿、既往结石史 |
| 妇科 | 子宫肌瘤、内膜增厚、卵巢囊肿、盆腔积液 | 月经情况、妊娠相关信息、妇科病史、复查影像 |
| 心脏 | 反流、瓣膜、射血分数、心包积液、室壁运动 | 心电图、心肌酶/BNP、胸闷气短、既往心脏病 |
