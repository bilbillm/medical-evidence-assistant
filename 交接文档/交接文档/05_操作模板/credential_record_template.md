# 钉钉/DEAP 凭证记录模板

> 不要把本文件提交到公开仓库或比赛材料。Client Secret、access_token、SSOSecret 等敏感内容只记录在本地安全位置，公开版本必须打码。

| 字段 | 值 | 是否敏感 | 备注 |
| --- | --- | --- | --- |
| 企业名称 |  | 否 | 用于确认组织环境 |
| CorpId |  | 中 | 公开材料中建议打码 |
| 应用名称 |  | 否 | 与 DEAP/开放平台保持一致 |
| 应用类型 |  | 否 | 企业内部应用/第三方企业应用/小程序/网页应用/DEAP 内部智能体 |
| AgentId |  | 中 | 内部应用常见标识 |
| Client ID / AppKey |  | 中 | 不建议公开完整值 |
| Client Secret / AppSecret |  | 高 | 严禁公开 |
| access_token 获取方式 |  | 高 | 应用访问凭证/用户授权凭证 |
| 权限范围 |  | 中 | 只申请最小必要权限 |
| 发布入口 |  | 否 | DEAP 链接/工作台/机器人/H5/小程序 |
| 日志入口 |  | 否 | DEAP 日志/开放平台日志/自建日志 |
